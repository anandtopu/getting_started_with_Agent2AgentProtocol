security reviews and grading rubrics. The flagship also has an encrypted Docker
deployment with real framework workers. Use the [validation report](../docs/VALIDATION_REPORT.md)
to distinguish verified behavior from external SDK/TCK limitations and deployment
responsibilities such as operating certificates and backups.
