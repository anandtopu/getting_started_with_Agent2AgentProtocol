Compare semantic values, not generated identifiers or object implementations.

Language interoperability rests on wire contracts, not shared Python objects. The TypeScript track pins the official JavaScript SDK and uses the same synthetic briefs. A test must cross the language boundary to demonstrate interoperability; a Python-only simulation is preparation rather than evidence.

Common wrong answers hard-code the happy path, overlook a negative case, or confuse transport fields with business data. Compare the reference with all acceptance cases. Design checks assess structure; use the human rubric for quality.
