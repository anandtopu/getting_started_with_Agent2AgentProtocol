# Quiz

1. What proves Python/TypeScript interoperability?
<details><summary>Answer</summary>An actual request crossing the native language boundary with equivalent states and quote artifacts.</details>

2. Must generated IDs match between languages?
<details><summary>Answer</summary>No. Compare semantics while retaining each task/context mapping.</details>

3. Where is the JavaScript SDK version pinned?
<details><summary>Answer</summary>package.json and package-lock.json, with native typechecking and network checks in CI.</details>

4. How do you prove the first learning objective?
<details><summary>Answer</summary>Compare JSON representations: run the first example, identify the response field or event, and compare it with the stored wire/result capture.</details>

5. What is the trust boundary in this lesson?
<details><summary>Answer</summary>Language interoperability rests on wire contracts, not shared Python objects. The TypeScript track pins the official JavaScript SDK and uses the same synthetic briefs. A test must cross the language boundary to demonstrate interoperability; a Python-only simulation is preparation rather than evidence.</details>

6. What should you do before consulting the reference solution?
<details><summary>Answer</summary>Write a prediction, run the starter, explain its failing assertion, then implement the required behavior and rerun the grader. For Design tasks, also apply the human rubric.</details>
